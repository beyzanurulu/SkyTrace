▲ SKYTRACE GitHub

PX4 · ArduPilot · open source

Flight log analysis with an assistant that cannot make up numbers.

Upload a drone flight log and SkyTrace finds the problems (GPS loss, a weak motor, vibration, a draining battery), shows the evidence, and answers questions about the flight. Every number in an answer is checked against the log.

Open the live demo ↗ Sample reports Source on GitHub

The demo runs on a free server: if nobody used it recently, the first load takes up to a minute. Chat works on the sample flights; your own logs are analysed but never sent to the cloud model.

Each report is a single HTML file that also works offline: timeline, findings and an evidence plot per finding.

How it works

  • ParsePX4 ULog and ArduPilot DataFlash into one schema.
  • DetectRule detectors with documented thresholds, plus optional anomaly detection.
  • AskAn agent with tools over the log answers questions; documentation passages are cited.
  • VerifyEvery number, finding id and link in an answer must come from a tool output, or it is flagged.

Run it on your machine

pip install "skytrace[web]"
skytrace analyze flight.ulg       # report + findings
ollama pull qwen2.5:7b            # local model for the assistant
skytrace serve                    # web UI on http://127.0.0.1:8000
